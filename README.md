# FoamStudio — downloads

Official installers for **FoamStudio**, a desktop workbench for OpenFOAM.
Product page, pricing and licence: <https://aboutkvs.vercel.app/FoamStudio.html>

## Download

**Windows 10/11 (64-bit):** [Download the latest installer](https://github.com/shanthoshkv/foamstudio-releases/releases/latest/download/FoamStudio-setup-win64.exe)

All versions and release notes: [Releases](https://github.com/shanthoshkv/foamstudio-releases/releases)

Each release lists the SHA-256 checksum of every file in `SHA256SUMS.txt`. Check it with:

```powershell
Get-FileHash .\FoamStudio-setup-win64.exe -Algorithm SHA256
```
